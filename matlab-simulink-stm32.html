MATLAB, Simulink and STM32

See how an idea in MATLAB becomes running code on an STM32, and how sensors and actuators connect to it. Click the boxes, move the sliders and watch the signal dots.

From MATLAB to a running STM32

function duty = ctrl(sp, adc)        % MATLAB Function block in Simulink
  persistent I; if isempty(I), I = 0; end
  temp = adc * 3.3 / 4095 * 100;     % ADC code to degC (LM35: 10 mV per degC)
  e    = sp - temp;                  % error
  I    = min(max(I + 0.05*e*0.1, 0), 1);   % integral term, sample time 0.1 s
  duty = min(max(0.1*e + I, 0), 1);  % PWM duty from 0 to 1
end

The same function runs in MATLAB, in a Simulink simulation and, after code generation, on the STM32.

Signal chain: sensor to actuator

Each dot is a signal travelling through the system. The analog path uses the ADC and PWM; the digital path uses a bus such as I2C or SPI and digital outputs.

Wiring checklist

  • STM32 logic is 3.3 V. Use level shifting for 5 V sensors.
  • Connect all grounds together: STM32, sensor, driver and supply.
  • Pins give only a small current. Use a MOSFET, driver board or relay module for motors, heaters and mains loads.
  • In Simulink use a fixed-step solver and match the model sample time to the loop speed you want on the target.
