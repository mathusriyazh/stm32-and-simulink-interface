ADC: voltage to digital value

A microcontroller only understands numbers. The ADC measures an analog voltage and turns it into a binary code.

1. Sample2. Hold3. Quantize4. Encode
Digital code = floor( Vin / Vref × 2n )  |  1 LSB = Vref / 2n

Blue line: analog input. Orange steps: value held after each sample and rounded to the nearest level.

Example: 8-bit, Vref 3.3 V, Vin 1.65 V gives floor(1.65/3.3 × 256) = 128 = 100000002. More bits means smaller steps and less error.

DAC: digital value to voltage

The DAC does the reverse of the ADC. Each bit adds a weighted share of the reference voltage. Click the bits to set a code.

Vout = code / 2n × Vref  (8-bit shown, Vref = 3.3 V)

Clock: the heartbeat

The clock sends regular pulses. Each pulse steps the processor, so a faster clock runs more instructions per second but uses more power. The animation speed is for illustration only.
