Embedded System: Block Diagram and Functions

An embedded system is a small computer built into a device to do one dedicated task. Select any block in the diagram to see what it does.

Select a block to read its function.

Main functions of an embedded system

Sensing

Reads real-world inputs such as temperature, light, motion or pressure through sensors.

Processing

The microcontroller runs the firmware, compares inputs against set conditions and decides what to do.

Control

Drives motors, relays, LEDs and displays so the device responds to what was sensed.

Real-time response

Completes each task within a fixed time limit, for example an airbag firing in milliseconds.

Data storage

Keeps the program in Flash/ROM and working data in RAM, plus logs if needed.

Communication

Exchanges data with other devices using UART, SPI, I2C, Wi-Fi or Bluetooth.

Monitoring and safety

Watches for faults, uses watchdog timers to recover from hangs, and saves power in sleep modes.

Working cycle

Sense→Convert (ADC)→Process→Decide→Act→Repeat
